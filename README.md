# Python Coder

Repositorio con los trabajos prácticos del curso de **Python en Coderhouse**.

Cada carpeta corresponde a un trabajo práctico (TP) entregado durante la cursada. Dentro de cada una vas a encontrar el código fuente, un README con la consigna y la nota recibida, y las instrucciones para ejecutar el script.

## Índice de TPs

| Módulo | Tema | Carpeta | Nota |
|--------|------|---------|------|
| 7b     | Manejo de archivos y persistencia de datos | [TP_Modulo_7b](./TP_Modulo_7b) | 90% |
| 7c     | JSON: datos estructurados | [TP_Modulo_7c](./TP_Modulo_7c) | 81% |
| 7 Final | Herramienta de procesamiento y persistencia (integrador) | [TP_Modulo_7_Final](./TP_Modulo_7_Final) | — |

> Los TPs se entregan formalmente como Google Docs en la plataforma del curso. Este repositorio funciona como respaldo de código ejecutable y portfolio.

## Cómo ejecutar cualquier TP

```bash
cd TP_Modulo_XX
python main.py
```

Requiere Python 3.10 o superior.
